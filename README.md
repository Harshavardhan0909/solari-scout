## 🚀 What is Solari Scout?

**Solari Scout** is an autonomous agent leveraging **Solari's cloud browsers** to track competitor pricing, features, changelogs, and job postings. It transforms raw web data into actionable executive intelligence without IP bans or blocking hassles.

### Why Cloud Browsers?
Competitive intel at scale is difficult. Local scrapers get blocked and trigger captchas. Solari's cloud browsers give you:
* 🌍 **Geo-Distributed Browsing:** See exactly what competitors show users in different global markets.
* 🛡️ **Anti-Detection:** Real browser fingerprints—no headless scraping tells.
* ⚡ **Parallel Sessions:** Monitor 50+ competitors simultaneously.
* 🔒 **Isolation:** Every session operates within a clean, secure sandbox.

Redeem code `STARTER1MO-MKY4BNDK` at [console.getsolari.com](https://console.getsolari.com) to get free credits.

### 2. Installation

Clone the repository and install dependencies:


# Correct syntax for README code blocks:
git clone https://github.com/Harshavardhan0909/solari-scout.git
cd solari-scout
pip install -r requirements.txt



### 3. Environment Configuration

Create your environment file and add your API keys:

```bash
cp .env.example .env

```

> **Note:** Open your `.env` file and add your `SOLARI_API_KEY` and `OPENAI_API_KEY`.

### 4. Run the Agent

* **Single competitor scan:**
```bash
python -m scout scan --url [https://competitor.com/pricing](https://competitor.com/pricing)

```


* **Full competitive briefing (multiple targets):**
```bash
python -m scout brief --config targets.yaml

```


* **Continuous monitoring (daily schedule):**
```bash
python -m scout monitor --config targets.yaml --schedule daily

```

## ⚙️ How It Works

1. **Browser Launch:** Scout requests a cloud browser instance from Solari's API configured with the target geo-location.
2. **Navigation & Extraction:** The browser loads target URLs, waits for dynamic content (SPAs, JS-rendered pricing grids), and extracts clean text.
3. **AI Analysis:** Raw extracted content is securely passed to an LLM using a specialized competitive intelligence prompt.
4. **Report Generation:** The LLM's findings are parsed into clean formats (Markdown, PDF, or Slack notification).
5. **Scheduling:** Built-in cron-based scheduling automates recurring updates.

## 📁 Configuration (`targets.yaml`)

```yaml
targets:
  - name: "Competitor X"
    urls:
      - [https://competitor-x.com/pricing](https://competitor-x.com/pricing)
      - [https://competitor-x.com/changelog](https://competitor-x.com/changelog)
      - [https://competitor-x.com/careers](https://competitor-x.com/careers)
    geo: "us-east"
    
  - name: "Competitor Y"
    urls:
      - [https://competitor-y.com/features](https://competitor-y.com/features)
      - [https://competitor-y.com/blog](https://competitor-y.com/blog)
    geo: "eu-west"

report:
  format: markdown
  output_dir: ./reports
  notify:
    slack_webhook: "${SLACK_WEBHOOK_URL}"

```
